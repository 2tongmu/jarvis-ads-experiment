## Issues Found & Fixed

### 1. **Non-existent AEL Bridge Functions**
**Problem:**
```python
de.de_create_new_schematic_view(LIB, CELL, VIEW)
de.de_get_design_context_from_name(LCV)
de.de_init_item("ads_rflib:C:symbol")
de.de_place_item(c1, 2.875, 0.0)
de.de_connect() / de.de_add_wire() / de.de_end()
de.db_create_pin(ctx, ...)
```
These functions do not exist in `keysight.ads.de`.

**Solution:** 
Mapped to proper Python API:
- `de.de_create_new_schematic_view()` → `de.View.create(cell, view_name, "schematic")`
- `de.de_get_design_context_from_name()` → `sch_view.get_design()`
- `de.de_init_item()` + `de.de_place_item()` → `design.add_instance(de.LCVName(...), (x, y), ...)`
- `de.de_connect()` + `de.de_add_wire()` → `design.add_wire([(x1,y1), (x2,y2), ...])`
- `de.db_create_pin()` → Port symbols via `ads_simulation:Term:symbol`

### 2. **HPEESOF_DIR Not Set Before Import**
**Problem:**
```
RuntimeError: HPEESOF_DIR must be set.
```

**Solution:**
Set `os.environ["HPEESOF_DIR"]` before importing `keysight.ads.de`:
```python
import os
os.environ.setdefault("HPEESOF_DIR", str(ADS_DIR))
```

### 3. **Cell/View Creation on Existing Workspace**
**Problem:**
```
RuntimeError: Could not find cell "cell_fetbias_switch_gate" in library "spdt_switch_pdk_lib".
RuntimeError: Error creating empty design: "...": Design already exists.
```

**Solution:**
- Check if cell exists; create if not: `if lib.cell_exists(CELL): ... else: de.Cell.create(lib, CELL)`
- Delete view if it exists before recreating: `if cell.view_exists(VIEW): cell.delete_view(VIEW)`

### 4. **Design Variables Format**
**Problem:**
```python
design.cell.write_design_variables({"Rs": "300 Ohm", ...})
# TypeError: expects List[Tuple[str, str]], not dict
```

**Solution:**
```python
design.cell.write_design_variables([
    ("Rs", "1000 Ohm"),
    ("Cp", "1 pF"),
])
```

---

### 5. **Unicode Encoding on Windows**
**Problem:**
```
UnicodeEncodeError: 'charmap' codec can't encode character '\u2192' in position 27
```
Arrow character `→` doesn't exist in Windows CP1252 terminal.

**Solution:**
Replace Unicode arrows with ASCII: `→` → `->`

---

### 6. **Design Save After Commit**
**Problem:**
```
RuntimeError: Attempt to save a read-only design.
```
After `tx.commit()`, the design becomes read-only in ADS. The transaction itself is responsible for persistence.

**Solution:**
Handle the exception gracefully; transaction commit is sufficient:
```python
try:
    design.save_design()
except RuntimeError as e:
    if "read-only" in str(e):
        print("Design is read-only after commit (transaction persists data)")
    else:
        raise
```

## Correct API Signatures (Verified)

### Create View
```python
de.View.create(cell: Cell, view_name: str, view_type_name: str) -> View
# Example: de.View.create(cell, "schematic", "schematic")
```

### Add Instance
```python
design.add_instance(lcv_name: de.LCVName, (x, y), name: str, angle: float) -> Instance
# Example: design.add_instance(de.LCVName("ads_rflib", "R", "symbol"), (4.25, 0.0), name="R1", angle=0.0)
```

### Add Wire
```python
design.add_wire(outline: List[Tuple[float, float]], *, layer_id=None) -> Line
# Example: design.add_wire([(1.375, 0.0), (2.875, 0.0), (4.25, 0.0), (5.25, 0.0)])
```

### Set Instance Parameters
```python
instance.parameters["PARAM_NAME"].value = "value_string"
# Example: r1.parameters["R"].value = "Rs"
```

### Set Cell Design Variables
```python
design.cell.write_design_variables(variables: List[Tuple[str, str]]) -> None
# Example: design.cell.write_design_variables([("Rs", "1000 Ohm"), ("Cp", "1 pF")])
```

### Transaction
```python
tx = de.db.Transaction(design, "label")
# ... add instances, wires, etc. ...
tx.commit()
# After commit, design becomes read-only; all changes are persisted
```
